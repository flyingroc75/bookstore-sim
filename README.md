# Bookstore Sim — prototype

A playable prototype of a bookstore management sim: haggle with sellers at the buy
counter, stock the shelves, ring up buyers before their patience runs out.
One 4-minute day, open to close, then the tally.

Play: https://flyingroc75.github.io/bookstore-sim/

Design notes live outside this repo (kept by the authors). Single-file HTML/JS, no build step.
