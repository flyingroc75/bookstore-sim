# Bookstore Sim — STABLE playtest build

The settled, shareable build of the bookstore management sim: haggle with sellers at
the buy counter, stock the shelves, ring up buyers before their patience runs out.

**Play:** https://flyingroc75.github.io/bookstore-sim/

This repo only changes when a build is approved for playtesting. Day-to-day iteration
happens in the dev repo (https://flyingroc75.github.io/bookstore-sim-dev/) — expect
that one to be unbalanced or mid-change.

Single-file HTML/JS, no build step. The build type ("stable build") is shown in the
game's top bar so playtesters can report which version they played.
